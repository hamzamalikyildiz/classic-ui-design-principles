# Tooling details

`audit` checks per element: spacing off the 4px grid (WARN; 6/10/14px half-steps and 4px fine-tunes off the 8px grid are INFO); text/background contrast against the composited background (translucent layers like `bg-white/10` are blended over their ancestors; CSS `body`/`html` background rules are detected as the page backdrop; Tailwind v3 palette, arbitrary hex, inline CSS `var()`/hex backgrounds, `dark:` pairs, shadcn HSL tokens for `:root` and `.dark` via `--css`; images and unknown/unparsed backgrounds are skipped; text on a gradient—including `bg-gradient-*` and Tailwind v4 `bg-linear-to-*`—is checked against every color stop) with same-hue fix suggestions; solid buttons per section/card; primary CTAs below 40px; nested radius; frame wrappers; nav link count; long paragraphs without a readable max-width; more than 2 fonts; lists without skeleton/empty states; `opacity-0` start states (`reveal-needs-js`). Sterility & mood checks: `stock-look` (default Tailwind blue/indigo/violet/purple/fuchsia accent with no custom palette and only neutral fonts, INFO), grey-only charts, borders on most cards with no shadows, flat type hierarchy; `playful|bold|trust` `low-color` and `no-hero-surface`; `playful` `no-drawn-mascot` & `card-sameness`; `bold` `bold-headline-size` & `bold-font-default`; `editorial` `headline-measure` / `left-stacked-column` / `edge-align` / `width-funnel` / `editorial-leading` / `no-serif`; `technical` `radius-too-soft` / `no-mono` / `shadow-heavy`. Dark neutral buttons on a dark page are not counted as primary CTAs. The audit cannot see rendered geometry (stretched cards, empty bands, visual focus); the screenshot review covers those.

`render.py` takes a full-page screenshot with headless Chrome/Chromium (Playwright). Needs `node`/`npm` for `axe-core` accessibility audits and offline fallback: if the Tailwind CDN or Google Fonts are unreachable, it installs/caches `tailwindcss@3` and `@fontsource` fonts under `~/.cache/uitools-render`, compiles Tailwind locally (including inline `tailwind.config`), and inlines font faces.

`audit` reads colors from inline `tailwind.config = { ... colors: { ink: '#123' } }` and Tailwind v4 `@theme { --color-x: #abc }`, and warns when a full page has no `<main>` landmark. In Playful and Bold (`EXPRESSIVE`), style rules (`grid`, `miller-7`, `single-primary-cta`, `grey-chart`, `max-2-fonts`, `no-hero-surface`, `border-heavy`, `no-drawn-mascot`, `card-sameness`, `bold-headline-size`, `bold-font-default`) are reported as INFO; accessibility, line length and `reveal-needs-js` stay at full severity.

`render.py --check` prints: horizontal page overflow (`page-overflow-x`, WARN), clipped or overflowing text and code boxes (`clipped-content`, WARN), invisible `opacity: 0` text (`invisible-content`, WARN), blank bands (`blank-band`, WARN), half-empty panels (`empty-panel`, WARN), short adjacent columns (`empty-column`, WARN), overlapping SVG labels (`overlapping-labels`, WARN), hollow stroked display text (`hollow-text`, WARN), desktop tiny body copy `<12px` (`desktop-tiny-text`, WARN), empty controls (`empty-control`, WARN), edge-clipped art (`edge-clipped-art`, INFO), axe accessibility violations (serious/critical = WARN), console/page errors (`js-errors`, WARN), missing focus rings (`no-focus-ring`, WARN), dead non-form buttons (`dead-buttons`, INFO), and 375px mobile checks (`mobile-overflow-x`, `mobile-tiny-text` = WARN; `mobile-tap-targets` = INFO).
