# Tooling details

`audit` checks per element: spacing off the 4px grid (WARN; Tailwind half-steps like 6/10/14px are INFO) or off the 8px grid (INFO); text/background contrast against the composited background (translucent layers like `bg-white/10` are blended over their ancestors; CSS `body`/`html` background rules are detected as the page backdrop; Tailwind v3 palette, arbitrary hex, `dark:` pairs, shadcn HSL tokens for `:root` and `.dark` via `--css`; images and unknown backgrounds are skipped; text on a gradient—including `bg-gradient-*` and Tailwind v4 `bg-linear-to-*`—is checked against every color stop) with same-hue fix suggestions; solid buttons per section/card; primary CTAs below 40px; nested radius; frame wrappers; nav link count; long paragraphs without a readable max-width; more than 2 fonts; lists without skeleton/empty states. Sterility checks: `stock-look` (default Tailwind blue/indigo/violet/purple/fuchsia accent with no custom palette and only neutral fonts, INFO), grey-only charts, borders on most cards with no shadows, flat type hierarchy; with `--mood playful|bold|trust` no hero surface, with `playful|bold` fewer than 3 hues, with `editorial` headline trapped in the reading measure / left-stacked column / width funnel / tight leading, with `technical` soft radii / no mono / heavy shadows. Dark neutral buttons on a dark page are not counted as primary CTAs. The audit cannot see layout results (stretched cards, empty areas, what the eye lands on); the screenshot review covers those.

`render.py` takes a full-page screenshot with headless Chrome/Chromium (Playwright). If the page uses the Tailwind CDN and the network is blocked, it compiles Tailwind locally with `npx tailwindcss@3`, including the page's inline `tailwind.config`, and inlines Google Fonts from `@fontsource` packages.

`audit` also reads colors from an inline `tailwind.config = { ... colors: { ink: '#123' } }` and Tailwind v4 `@theme { --color-x: #abc }`, and warns when a full page has no `<main>` landmark. In Playful and Bold the style rules (grid, CTA count, fonts, depth, mascot, headline size) are reported as INFO; accessibility, line length and hidden-content findings keep full severity.

`render.py --check` (needs Playwright and Chrome; installs `axe-core` through npm on first use) prints: clipped or overflowing text and code boxes, blank bands, panels more than half empty, columns that end far above their row (`empty-column`), overlapping SVG labels, content with opacity 0 after load, buttons without text or label, axe violations (serious/critical = WARN), console/page errors, 375px mobile overflow and tiny text, buttons that change nothing when clicked, missing focus rings.
