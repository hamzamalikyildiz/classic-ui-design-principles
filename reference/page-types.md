# Page-type matrix

Always-on baseline: WCAG AA, 8pt grid, semantic colors, max 2 fonts (up to 3 in expressive moods), modular scale, one hero surface per screen (except pure typographic Editorial), single primary CTA, depth over borders (except Technical/Editorial hairlines), Jakob, proximity.

| Page / screen type | Default mood | Layout & structure | Key states (reference/states.md) | Premium moment (reference/motion.md) |
|---|---|---|---|---|
| **Landing / marketing** | Bold (Playful for kids/consumer) | Z-pattern, full-width sections (mood spacing), Fitts hero CTA, focal hero visual/demo, brief-driven bento/features | Demo/form loading, inline error, success state | Hero entrance + stagger (`30–50ms`, ≤6); tactile CTA press (`80ms`) & card lift |
| **Auth (sign-in / sign-up / password reset / 2FA)** | Trust (or brand's) | Single column `max-w-sm`–`max-w-md`, show/hide toggle, Fitts mobile submit | Preserve email on error; inline field error without jarring shake; locked state | Live password strength / auto-advance 2FA cells with smooth focus shift |
| **Onboarding / setup wizard** | Trust or Playful | Single column `max-w-md`–`max-w-lg`, Hick step indicator (`≤5`), progressive disclosure | Resumable progress, inline error, `>3s` staged provisioning | Instant preview of user choices; completion check draw (`220ms`) |
| **Dashboard / overview** | Trust (Technical for dev/ops) | F-pattern, sidebar (grouped by task, about 5–7 per group) or 12-col grid (`gap-4`/`gap-6`), hero KPI surface + companion panels, `tabular-nums`, categorical chart colors | Skeleton (`1–3s`), partial (`—`/`"Pending"`), stale/revalidating badge, error retry | Score count-up + score ring / sparkline draw (`500ms --ease-enter`) |
| **List / index (table, filters, bulk actions)** | Trust or Technical | Filter bar + count, table or card grid (catalog: Hick grouped filters, 1 CTA/card) | First-use vs filtered empty state (`"0 matches"` + `"Clear filters"`), skeleton, error | Optimistic row add/archive with `0fr->1fr` or fade + sticky bulk-action bar slide-up + Undo toast |
| **Detail / workspace view** | Trust or Technical | Header summary + tabbed/split panes, sticky actions | Skeleton->content crossfade, `>3s` staged progress, partial data, locked badge | Shared-element transition from list title; accepted-item `1.2s` row highlight + live score/status update |
| **Editor / multi-step form** | Trust or Technical | Focused canvas/form (`max-w-md`–`max-w-lg`), keyboard shortcut hints (`⌘S`), Fitts mobile submit | Non-blocking auto-save indicator `"Saved 2s ago"`, dirty-state guard, offline draft, inline error | Section collapse (`0fr->1fr`) & subtle save-check morph (`220ms`) |
| **Settings / preferences** | Trust | Grouped sections separated by whitespace, side nav (grouped, about 5–7 per group), Jakob | Instant toggle feedback or explicit section Save bar, re-auth lock, error rollback | Reachable `System / Light / Dark` theme switch with sliding pill (`220ms`) |
| **Billing / plan & usage** | Trust | Usage progress bars with thresholds, transparent plan comparison with single highlighted tier, invoice table `tabular-nums` | Locked-feature upgrade explanation (why + value preview + `"Upgrade"`), payment error | Usage bar fill (`500ms --ease-enter`) & cycle toggle with instant `tabular-nums` swap |
| **Search results / command discovery** | Trust or Technical | Query highlight in matches, facets/category tabs, arrow nav (`↑/↓`, `Enter`) | `<1s` no-flash filter, `1–3s` skeleton, zero-results recovery suggestions + `"Clear filters"` | Facets/category tabs with sliding indicator (`220ms --ease-standard`) & zero-CLS settle |
| **Notifications / inbox / activity feed** | Trust | Grouped by time bucket `"Today" / "Yesterday"`, unread dot, inline quick action | All-caught-up empty state, optimistic read/archive, stale polling, offline cache | Unread dot + batch mark-as-read transition (`0fr->1fr` collapse, `220ms`) + Undo toast |
| **Error & system pages (404 / 500 / maintenance)** | Trust or brand's | Centered `max-w-md`, calm human explanation, error correlation ID in `mono`, direct recovery CTA + status timestamp | Live status timestamp, maintenance ETA, preserved draft notice | Copy-ID checkmark morph (`220ms`) & tactile primary recovery CTA (`"Retry"`) |
| **First-use empty screen** | Trust or Playful | Explains value in 1 sentence, preview/template starter cards, single primary creation CTA — never a blank void | Template skeleton, sample-data sandbox badge, import error recovery | Staggered starter cards (`30–50ms`) & smooth crossfade into populated workspace |
| **Modal / drawer / command palette (`⌘K`)** | Page's mood | Nested radius (`p-4`/`p-6`, `max-w-md`–`max-w-lg`), strict focus trap + `Esc` close, primary CTA bottom-right with ghost cancel left | In-flight submit lock, inline error inside dialog (keep input), empty command query | Backdrop fade + panel translate/scale (`220–320ms --ease-enter`, exit `150ms`) |
| **Article / documentation / long-form report** | Editorial (Technical for API) | `max-w-prose` 45–75ch, `18px`/`1.7` leading, `text-balance` headings + `text-pretty` body, earned diagrams only | Code copy feedback, anchor highlight, async embed fallback | Sticky TOC active-section highlight (`150–220ms`) & tab opacity crossfade |

**Cross-screen rules:** Nav/menus use Jakob + Miller (about `5–7` items per group as a starting size, accent active state). Mobile screens use `16px` padding, `44–48px` targets with bottom-zone CTA (Fitts), and `≤5` tab bar items.

The user's explicit request wins over the matrix. Keep every requested item; when a request collides with a rule (10 menu items, three buttons vs. single CTA), satisfy the rule through presentation (grouping, "More" menus, outline/ghost variants) and say so in the report. Report any other deliberate deviation with its reason.

**No extra moods.** Map unusual briefs onto these five: luxury/fashion → Editorial with a Bold hero; e-commerce → Trust base with a Bold hero band; mobile app → the brand's mood; internal tools → Technical or Trust. Dark mode is a theme, not a mood.
