# Generator prompts

Superseded: `make_tasks.py` writes one task file per page (see `PROTOCOL.md`; defaults to `--briefs r,m`, with optional `v` vague briefs in `briefs.json`). The two arms differ only in this paragraph:

- **Skill arm:** read SKILL.md, the mood file, `reference/visual-quality.md`, and `reference/rules.md` (when fixing findings), then run `uitools.py audit` and `render.py --check`, fix warnings, up to 2 rounds.
- **No-skill arm:** do not read the skill folder; render with `render.py` (no `--check`), look at the screenshot, fix what looks wrong, up to 2 rounds.

Judge prompt: `JUDGE_PROMPT.md` plus a persona from `judges.json`, generated by `make_judge_sets.py`.
