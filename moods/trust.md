# Trust mood notes

- One accent plus neutrals, `shadow-sm`, 12-16px radius, one hero accent card/band per screen.
- Give the page a data story, not just KPI cards: an annotated chart (event marker or threshold line with a one-line explanation), a status band for the one thing that needs attention (overdue invoice, failed payment), and a ranked list with trend sparklines.
- Fill every panel (see Technical notes on half-empty panels); tables show 8+ rows, charts have labelled axes and a legend.
- Semantic colors carry state (red/amber/green) and always come with text or an icon.

Content floor: top bar or page header with actions, 4+ KPIs with deltas, a multi-series chart with legend, a ranked or status list, a table or log stream, one alert/empty/error state shown, a code or detail panel where relevant.
